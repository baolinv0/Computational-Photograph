# 生成式参考驱动的低光恢复：生成的目标能否成为可信证据？
版本 v0.1｜2026-11-18｜主 T03，次 T02/T06/T05
目录：[问题边界](#问题边界) · [竞争路线](#竞争路线) · [证据](#证据) · [系统方案](#系统方案) · [判断与缺口](#判断与缺口) · [References](#references)

## 问题边界
研究低光图只有有限观测时，如何在提升纹理与曝光的同时避免引用不对应、生成错误细节。**生成的正常曝光参考**与来自第二传感器/第二帧的**真实观测**是两种数据角色：前者提供的是目标先验，不能单凭其外观推定事实。

## 竞争路线
| 路线 / 历史锚点 | 训练数据 | 在线输入 → 控制 → 输出 | 主要风险 |
|---|---|---|---|
| Zero-DCE / EnlightenGAN (历史) | 无 GT 曲线损失 / 非配对亮图 | LQ → 可调曲线 / 风格分布 → 增亮图 | 真实细节不受标定 |
| RetinexFormer / AnlightenDiff (历史) | 配对或合成暗亮数据 | LQ → illumination / diffusion anchor → 输出 | 同域训练与未知复杂退化 |
| MR. Illuminate (历史) | 生成先验 | LQ → 生成先验条件 → 明亮图 | 生成可信度 |
| **MrLIE 2611.19285 (2026-11-14 新)** | 无严格对齐真实 paired HQ；模型生成参考及条件训练 | LQ → MLLM 造参考/自纠→ COM offset/confidence→SAI 源结构约束 diffusion → 输出 | 同输入自生成目标不是独立新增测量，参考错配易致虚构 |
| UGD-FM 2611.06422 (独立真实观测路线) | 真实 RGB/NIR 成对观测和合成噪声 | LQ RGB + measured NIR → sparse align + flow → 输出 | 视差、遮挡与硬件成本 |
| AutoRef / HarnessIR (方法桥接，不是直接方法继承) | 多参考图生成或真实恢复策略的独立任务 | harness/证据编排→模型执行→验收 | 不能证明参考事实与生成幻觉等价 |

## 证据
- [MrLIE 卡](../papers/arxiv-2611.19285.md)：作者 U3D ablation 报 NIQE 3.234→2.884、BRISQUE 7.258→5.368；这些是无参考感知代理，不能判定建筑、文字、人脸纹理真实性。
- [UGD-FM 卡](../papers/arxiv-2611.06422.md)：NIR 是独立传感器观测，不能据此将其可靠性转移到自生成 daylight reference。
- 强简单基线：固定 LQ source anchored diffusion、不生成 reference；或低成本判别式 Retinex；要求预算对齐，含 MLLM 迭代+diffusion calls。

## 系统方案
**离线**：获得低光原图及自然亮图分布→构造生成参考、置信对应与结构保持训练，划分真实设备/跨光照/运动遮挡测试，记录参考失败率。
**在线**：输入观测 → 自生成 daylight prior（非物理 GT）→匹配置信+源结构锚点 → 输出候选 → 判断来源保真/伪影；若拒绝回退到低幻觉基线。
**Agent 控制层（待验证组合）**：决定是否需要生成参考及是否承认该区域可迁移，比较可达性/可发现性/可选择性，不把“MLLM 自我批评”当作独立真实正确性验证。

## 判断与缺口
此前判断：参考可帮助细节。**新证据**强调若参考来自输入的生成模型，必须同时做置信几何对齐与输入结构锚点。**当前判断 PROBE**：有增益但未证实事实上更准确；真实纹理、文字、人物和相机 OOD 尚待独立证据，主方案不直接改。
最小判别实验：固定恢复骨干、调用预算和输入，比较无参考、生成参考、真实独立参考三路，按置信分桶测 GT 结构/文字真实性及人工偏好。
记忆锚点：**生成参考能提出合理细节，不等于额外测量已经观察到这些细节。**
