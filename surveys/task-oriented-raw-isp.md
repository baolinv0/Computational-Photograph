# 任务导向 RAW ISP：重建保真与机器感知目标
2026-11-24｜T01 主，T03/T04/X01 次｜本页与[场景条件化照片 ISP](scene-conditioned-neural-isp.md)的目标不同，不复制照片渲染路线；与[选择性任务恢复](selective-task-aware-restoration.md)互补。
## 问题边界
给定 Bayer RAW、传感器元信息和已知检测/分割任务，怎样分配重建与 ISP 自适应能力？输出是任务可用 RGB 与预测，不假设机器任务最优等于人眼照片最优。不讨论新增物理观测。
## 竞争路线
| 路线 | 输入/输出 | 控制变量 | 监督与边界 |
|---|---|---|---|
| 固定重建 + 任务网络 | RAW→RGB→任务 | 下游参数 | 重建和任务分别优化，强简单基线 |
| AdaptiveISP / TA-ISP | RAW或RGB→任务相关渲染→任务 | ISP动作、参数、区域 | task loss；任务相关渲染非人眼偏好；TA-ISP arXiv 2509.13762 |
| RAW-Adapter | RAW→感知模型 | 输入适配与任务表征 | 不必将可展示RGB作为唯一中介；本轮只核验路线摘要 |
| SegDem | Bayer→RGB | 语义相关重建特征 | 2608.07916，Dem2TA 明确使用前序预训练基础；其余历史消融待全文补齐 |
| Dem2TA | Bayer→demosaic→WB/CCM/gamma→局部tone/color/detail→任务 | 前端重建、表征对齐、后端参数 | 重建GT、DINO、任务表征与任务损失；两阶段训练 |
## 证据与判断
[Dem2TA](../papers/arxiv-2611.27209.md) v1 Table4：下游仅适配77.262、联合无对齐77.379、表征对齐80.023、完整81.152 IoU；主要证据支持表征对齐，不是阶段划分本身（同步完整81.047）。Table3 S模型重建PSNR44.2218→42.7870、IoU77.064→80.495；下游也变化，不等于降低PSNR导致任务提升。Table2 100真实RAW、1112人工复核SAM3 masks、box prompts，TA-ISP同前端82.890→83.519 IoU；不是通用检测/人眼质量/部署证据。
旧判断：先得到最忠实RGB再适配任务。新证据：在目标已知、联合训练且有监督时，任务相关重建表征可产生增量；传统重建目标仍是照片、人眼保真、未知任务的重要基线。尚非跨团队共识。
## 系统回忆
离线：RAW/线性RGB GT/任务标注 → 固定色彩基础变换 → 联合重建与任务网络+表征监督 → 冻结重建 → 局部tone/color/detail与任务模型适配。在线：RAW→重建→基础ISP→局部参数→任务头；训练辅助分支移除。Agent层可选择目标/策略，但未由该论文验证。
验收：同数据/任务网络/训练预算比较固定重建、联合无对齐、表征对齐、局部渲染。独立测真实留出传感器、任务指标、RGB fidelity、端到端延迟功耗。复杂联合方法不能仅按FLOPs评价，当前未有手机部署实测。
