# OLiVES：同步采集的户外低照视频增强与分割基准

- **身份**：arXiv:2610.20501
- **首次公开（已核）**：2026-10-14，v1
- **本次核验**：2026-10-16；selected sections
- **独立复现**：未进行

## 快速回忆

**问题**：动态视频低照基准常用顺序重拍或合成退化，难同时获得对齐的正常/低照参考与下游任务标注。

**机制**：beam splitter + 双机 genlock + RED V-RAPTOR，并用不同 ND filter 同步采集成对视频。

**证据**：作者报告 25,254 对对齐帧与 46,366 个分割标注，联合测增强和分割；部分训练 mask 由 SAM2 生成且未人工逐一核验。

**决策边界**：这是 RGB 视频而非 RAW/ISP；低照由白天 ND 滤镜模拟，噪声与颜色统计不等同真实夜景。单一地区、受控 tripod/dolly/jib，不含 handheld/aerial；数据下载尚未完成核验。

**下一步**：先确认数据实际可用与许可证；做真实夜景跨域、手持运动、灯频闪、白平衡漂移和 segmentation-on-restored-image 失效分析。

## 精读记录

- 同步采集比顺序重拍更适合评估动态场景，但 ND 模拟仍是关键域差。
- 下游分割让“看起来更亮”与“任务更可用”可以分开检验。
- **可能关联**：适合作为视频增强—下游任务联动基准的结构模板，不应直接当手机夜景真值。
